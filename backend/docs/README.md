# API Docs and DB Schema

## Swagger UI
- Start backend: `cd backend && npm install && npm run server`
- Open: `http://localhost:5000/api-docs`

Swagger spec source:
- `backend/docs/openapi.js`

## DB Schema Diagram
Mermaid ER diagram source:
- `backend/docs/db-schema.mmd`

Render options:
1. Paste into https://mermaid.live
2. If Mermaid CLI is installed: `mmdc -i backend/docs/db-schema.mmd -o backend/docs/db-schema.png`
